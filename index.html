🎛️ Samplers & Parameters Explained

🌡️ Temperature

Controls the randomness of the replies. Values between 0.50 – 0.80 are ideal for realistic/coherent roleplay, keeping characters in-personality. Values above 1.00 unlock pure creativity, but can eventually result in gibberish or prompt leaking.

🌊 Top P (Nucleus Sampling)

Limits the model's word selection to a percentage of the most likely words. For example, 0.90 means only the top 90% of words are considered, discarding the bottom 10% of weird/unrelated choices. Keep it at 1.00 to disable filtering, or 0.90 – 0.95 to prune outliers.

🎯 Top K

Filters the model's selection pool to exactly the N highest-ranking words. Lower values (e.g. 40) keep replies extremely consistent, whereas higher values allow more vocabulary diversity. Set to 0 to disable it (relying solely on Top P).

♻️ Repetition Penalty

Prevents the model from repeating identical phrases or getting stuck in loops. A value of 1.00 is default (no penalty). Optimal settings for roleplay range from 1.08 to 1.18. Values above 1.25 can cause the model to generate broken grammar to avoid standard words.

📏 Max Response Length (Tokens)

Restricts how long a single model response can be. 1 token is roughly 0.75 words. 512 - 1024 tokens is standard for detailed replies. Set it higher if you enjoy reading novel-length paragraphs.
